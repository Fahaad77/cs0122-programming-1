Full Program

Search review

public class CourseReviewPractice {
    public static void main(String[] args) {
        int[] values = {4, 8, 15, 16, 23, 42};
        int target = 16;
        boolean found = false;

        for (int i = 0; i < values.length; i++) {
            if (values[i] == target) {
                System.out.println("Found at index " + i);
                found = true;
                break;
            }
        }

        if (!found) {
            System.out.println("Target not found");
        }
    }
}

Debug

Cumulative mistakes

  • Class name and file name do not match.
  • Used = instead of ==.
  • Loop condition uses <= length.
  • Forgot to update a loop counter.
  • Integer division gives an unexpected result.

Practice

Final cumulative prompts

  • Count values greater than 10.
  • Find the smallest value.
  • Print all values and their indexes.
  • Convert the array to user input.
