Week 1 Lab

First Java Program in VS Code

Set up the workflow, compile and run a Java file, modify output, and debug small syntax errors.

ToolVS Code terminal
FileHelloCS0122.java
FocusJDK, class, main, output, comments
Open starter Java

Setup check

  1. Open VS Code and the integrated terminal.
  2. Run java -version.
  3. Run javac -version.
  4. Create a folder named week01-first-program.

Starter program

public class HelloCS0122 {
  public static void main(String[] args) {
    // First CS0122 Java program
    System.out.println("Welcome to Programming 1");
    System.out.print("Java runs through ");
    System.out.println("the JVM.");
  }
}

Run and explain

  1. Predict the output before compiling.
  2. Compile with javac HelloCS0122.java.
  3. Run with java HelloCS0122.
  4. Identify the source file and bytecode file.
  5. Explain which command compiles and which command runs.

Modify and debug

  1. Add a second comment explaining the purpose of main.
  2. Add one line using \n and one line using \t.
  3. Change one println to print and predict the output.
  4. Remove one semicolon, compile, record the first error, then fix it.
  5. Change main to Main, run, record what happens, then fix it.

Submit

Submit HelloCS0122.java plus a short note listing the compile command, run command, output, and one error you fixed.
