Students predict and explain the Java workflow before writing more code.

Part A: Sort the execution pipeline

Arrange the cards from source code to visible output.

  1. JVMExecutes bytecode on this computer.
  2. Source codeThe .java file written by the programmer.
  3. OutputWhat appears in the terminal.
  4. Compilerjavac checks and translates source code.

Arrange the cards, then check your answer.

Part B: Classify instruction types

Use the six categories from the slides: input, processing, logical, repetition, output, and storage. For logical and repetition, classify the idea only; do not write decision or loop code yet.
