Full Program

Project polish

import java.util.Scanner;

public class ProjectPolish {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        String[] names = new String[3];
        int[] scores = new int[3];

        for (int i = 0; i < names.length; i++) {
            System.out.print("Name " + (i + 1) + ": ");
            names[i] = input.nextLine();
            System.out.print("Score: ");
            scores[i] = input.nextInt();
            input.nextLine();
        }

        System.out.println("Report");
        for (int i = 0; i < names.length; i++) {
            String status = scores[i] >= 60 ? "Pass" : "Needs support";
            System.out.println(names[i] + " - " + scores[i] + " - " + status);
        }
        input.close();
    }
}

Predict

Boundary thinking

What status prints when the score is 60? What about 59? Explain using the condition.

Debug

Scanner line issue

After nextInt(), use nextLine() to consume the end of the line before reading the next name.

Optional

Enrichment boundary

Optional improvements may make output cleaner, but required CS0122 work remains variables, input, expressions, selection, loops, arrays, and matrices.

Recap

Project completion checklist

  • Every feature has a test case.
  • Every loop has a purpose.
  • Every array index is checked.
  • You can explain the program without reading every line.
