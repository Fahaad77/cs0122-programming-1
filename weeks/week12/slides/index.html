Hook

The lab is a workflow

Most mistakes happen from rushing. A strong workflow catches errors while the program is still small.

Concept

Lab workflow

Read->Plan->Code small->Compile->Test->Trace

Checklist

Before coding

  • What input is required?
  • What output is required?
  • Which variables and arrays are needed?
  • Which loops and conditions are needed?
  • What simple test case proves the logic?

Full Program

Integrated practice

import java.util.Scanner;

public class LabReadinessPractice {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] values = new int[6];

        for (int i = 0; i < values.length; i++) {
            System.out.print("Value " + (i + 1) + ": ");
            values[i] = input.nextInt();
        }

        int evenCount = 0;
        int total = 0;
        for (int value : values) {
            total += value;
            if (value % 2 == 0) {
                evenCount++;
            }
        }

        System.out.println("Total: " + total);
        System.out.println("Even count: " + evenCount);
        System.out.printf("Average: %.2f%n", (double) total / values.length);
        input.close();
    }
}

Modify

Extend safely

  • Add min and max.
  • Add count above average.
  • Keep each feature separate while testing.
  • Do not rewrite working code unless necessary.

Debug

Common lab errors

for (int i = 0; i <= values.length; i++) // bounds error
if (value % 2 = 0)                   // assignment error
average = total / values.length;      // integer division risk

Trace

Compiler vs logic error

Error typeWhat happensFirst response
CompilerProgram does not runRead first message
LogicProgram runs but answer is wrongTrace variables

Practice

Mini lab prompts

  • Count values divisible by 3.
  • Find the largest input.
  • Print only values above the average.
  • Stop and explain each loop condition.

Recap

Lab-ready habits

  • Plan before typing.
  • Compile early.
  • Use small tests.
  • Trace values when output surprises you.
