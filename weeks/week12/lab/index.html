Objective

Practice complete beginner Java programs that combine selection, loops, arrays, tracing, and debugging.

Starter code

import java.util.Scanner;

public class LabReadinessPractice {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] values = new int[6];

        for (int i = 0; i < values.length; i++) {
            System.out.print("Value " + (i + 1) + ": ");
            values[i] = input.nextInt();
        }

        int evenCount = 0;
        int total = 0;
        for (int value : values) {
            total += value;
            if (value % 2 == 0) {
                evenCount++;
            }
        }

        System.out.println("Total: " + total);
        System.out.println("Even count: " + evenCount);
        System.out.printf("Average: %.2f%n", (double) total / values.length);
        input.close();
    }
}

Required tasks

  1. Run the starter and trace total and evenCount.
  2. Add a count of values greater than the average.
  3. Add min and max calculations.
  4. Create three test cases: mixed values, all even values, and all odd values.
  5. Write a short debugging note for one mistake you fixed.
  6. Submit only your own completed Java file and trace table.
