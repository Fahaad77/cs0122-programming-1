Week 7 Practice

Midterm Practice Pack

Non-confidential practice for tracing and debugging.

Practice prompts

  1. Write a loop that counts valid values.
  2. Write an if/else-if ladder for categories.
  3. Explain integer division and casting using one example.
  4. Find the error in a switch without break.

Readiness checklist

  • I can compile and run from VS Code.
  • I can trace a loop by hand.
  • I can choose if vs switch.
  • I can debug one compiler message at a time.
