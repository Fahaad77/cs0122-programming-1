Section 01

Why arrays?

Arrays store multiple values of the same type under one variable name.

Concept

Many boxes, one name

grades[0]90index 0
grades[1]85index 1
grades[2]77index 2

Syntax

Declare and create

int[] grades;
grades = new int[5];

String[] names = {"Sara", "Ali", "Mona"};

Rule

Indexes start at 0

An array of length 5 has indexes 0, 1, 2, 3, 4. The last valid index is length - 1.

Access

Read and update elements

grades[0] = 95;
grades[1] = 88;
System.out.println(grades[0]);
grades[1] = grades[1] + 2;

Full Program

Read grades with Scanner

import java.util.Scanner;

public class GradesArray {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] grades = new int[5];
        int sum = 0;

        for (int i = 0; i < grades.length; i++) {
            System.out.print("Grade " + (i + 1) + ": ");
            grades[i] = input.nextInt();
        }

        System.out.println("Stored grades:");
        for (int i = 0; i < grades.length; i++) {
            System.out.println("Index " + i + " = " + grades[i]);
            sum += grades[i];
        }

        double average = (double) sum / grades.length;
        System.out.printf("Average: %.2f%n", average);
        input.close();
    }
}

Debug

ArrayIndexOutOfBoundsException

int[] values = {4, 8, 15};
System.out.println(values[3]); // indexes are 0, 1, 2 only

Use i < values.length, not i <= values.length.

Modify

Find maximum starter idea

int max = grades[0];
for (int i = 1; i < grades.length; i++) {
    if (grades[i] > max) {
        max = grades[i];
    }
}
