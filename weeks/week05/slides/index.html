Section 01

Why loops?

Loops repeat a block while a condition remains true.

Initialize->Check->Body->Update

Vocabulary

Four loop parts

  • Initialization: starting value.
  • Condition: boolean question.
  • Body: repeated statements.
  • Update: progress toward stopping.

Syntax

while loop

int counter = 1;
while (counter <= 10) {
    System.out.println(counter);
    counter++;
}

Full Program

Print 1 to 10 with while

    public static void main(String[] args) {

Section 02

for loops

A for loop keeps count-controlled repetition details in one header.

Syntax

for loop anatomy

for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
int i = 1->i <= 10->body->i++

Full Program

Print 1 to 10 with for

public class ForOneToTen {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            System.out.println(i);
        }
    }
}

Example

Count backwards

for (int i = 10; i >= 1; i--) {
    System.out.println(i);
}

Full Program

Sum numbers 1 to N

import java.util.Scanner;

public class SumToN {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("N: ");
        int n = input.nextInt();
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        System.out.println("Sum = " + sum);
        input.close();
    }
}

Full Program

Multiplication table

import java.util.Scanner;

public class TableForNumber {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number: ");
        int number = input.nextInt();
        for (int i = 1; i <= 10; i++) {
            System.out.println(number + " x " + i + " = " + (number * i));
        }
        input.close();
    }
}

Sentinel

Repeat input until stop value

int total = 0;
System.out.print("Value, 0 to stop: ");
int value = input.nextInt();
while (value != 0) {
    total += value;
    System.out.print("Value, 0 to stop: ");
    value = input.nextInt();
}

Recap

Loop safety checklist

  • Initialize before checking.
  • Condition must eventually become false.
  • Update the right variable.
  • Trace before running.
