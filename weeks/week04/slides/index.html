Full Program

Positive, negative, or zero

import java.util.Scanner;

public class NumberSign {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number: ");
        int number = input.nextInt();

        if (number > 0) {
            System.out.println("Positive");
        } else if (number < 0) {
            System.out.println("Negative");
        } else {
            System.out.println("Zero");
        }
        input.close();
    }
}

Concept

Ternary operator ?:

Use the ternary operator only for a short value choice, not for complex logic.

String parity = number % 2 == 0 ? "even" : "odd";

Section 02

switch/case selection

Use switch when one expression is compared to fixed values.

Full Program

Restaurant menu switch

import java.util.Scanner;

public class RestaurantMenu {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.println("1. Burger");
        System.out.println("2. Pasta");
        System.out.println("3. Salad");
        System.out.print("Choice: ");
        int choice = input.nextInt();

        switch (choice) {
            case 1:
                System.out.println("Burger selected");
                break;
            case 2:
                System.out.println("Pasta selected");
                break;
            case 3:
                System.out.println("Salad selected");
                break;
            default:
                System.out.println("Invalid choice");
        }
        input.close();
    }
}

Predict

Missing break behavior

int choice = 2;
switch (choice) {
    case 1: System.out.println("Burger");
    case 2: System.out.println("Pasta");
    case 3: System.out.println("Salad");
    default: System.out.println("Invalid");
}

Rules

When switch is appropriate

  • Good: exact menu numbers, letter codes, simple command words.
  • Not good: ranges such as GPA >= 4.5.
  • Use default for unexpected values.
  • Use break unless fall-through is intentional.

Validation

Guard bad input

if (choice < 1 || choice > 3) {
    System.out.println("Choose 1, 2, or 3.");
} else {
    System.out.println("Processing choice " + choice);
}

Recap

Selection checklist

  • Conditions must be boolean.
  • Braces protect blocks.
  • Order matters in else-if ladders.
  • switch compares exact values.
  • Validation should happen before trusting input.
