Starter structure

import java.util.Scanner;

public class ShoppingBill {
  public static void main(String[] args) {
    final double VAT_RATE = 0.15;
    Scanner input = new Scanner(System.in);

    System.out.print("Item name: ");
    String itemName = input.nextLine();

    System.out.print("Unit price: ");
    double unitPrice = input.nextDouble();

    System.out.print("Quantity: ");
    int quantity = input.nextInt();

    double subtotal = unitPrice * quantity;
    double vat = subtotal * VAT_RATE;
    double total = subtotal + vat;

    System.out.printf("Subtotal: %.2f%n", subtotal);
    System.out.printf("VAT: %.2f%n", vat);
    System.out.printf("Total for %s: %.2f%n", itemName, total);

    input.close();
  }
}

Required extensions

  1. Add a deliveryFee variable and include it with total += deliveryFee;.
  2. Create int wholeRiyals = (int) total; and explain what casting removed.
  3. Ask for totalMinutes and print hours plus remaining minutes using / and %.
  4. Add one output line that would be wrong without parentheses, then fix it.
  5. Create two boolean expressions, such as enoughCash and largeOrder, and print them. Do not use them in if statements.
  6. Use printf for all money output.

Predict, run, compare, explain

  1. Predict: before running, calculate subtotal, VAT, total, whole riyals, hours, and remaining minutes by hand.
  2. Run: enter one complete test case in the VS Code terminal.
  3. Compare: place your predicted values beside the actual output.
  4. Explain: write one sentence for each mismatch, especially integer division, modulus, casting, and string concatenation.

Small decimal differences can happen because money uses decimal formatting. Use printf to show two digits after the decimal.

Debug checks

  • 5 / 2 gives 2; use 5 / 2.0 or a cast when a decimal is needed.
  • += is one operator; + = is invalid.
  • = assigns; == compares.
  • <= and >= cannot be reversed.
  • String concatenation needs parentheses when arithmetic should happen first.
