Section 03

Evaluation Order

Precedence and parentheses decide what Java evaluates first.

Precedence

Week 3 precedence ladder

FirstParentheses( )
ThenIncrement/decrement on a single variable++ --
ThenMultiplication, division, remainder* / %
ThenAddition, subtraction, string joining+ -
Later in traceRelational/logical produce booleans> == && ||
LastAssignment stores the final value= +=

Visual Model

Expression evaluation tree

2 + 7 * 4->7 * 4
first->2 + 28->30

Multiplication happens before addition unless parentheses change the order.

Associativity

Same-precedence operators go in order

int a = 20 / 5 * 2;
int b = 20 / (5 * 2);

For *, /, and %, Java evaluates left to right unless parentheses say otherwise.

Section 04

Division and Remainders

Integer division and modulus are deliberate tools, not accidents.

Integer Division

Whole numbers give whole-number division

int students = 10;
int groups = 3;
System.out.println(students / groups);

The result is 3, not 3.333....

Modulus

Modulus gives the remainder

int students = 10;
int groups = 3;
System.out.println(students % groups);

The result is 1. One student remains after making groups of three.

Try It

Time converter

int totalMinutes = 125;
int hours = totalMinutes / 60;
int minutes = totalMinutes % 60;
System.out.println(hours + " hours");
System.out.println(minutes + " minutes");

Section 05

Type Conversion

Know when Java widens automatically and when a cast is required.

Numeric Promotion

Automatic widening

int->long->float->double
int quantity = 3;
double price = 7.50;
double subtotal = quantity * price;

Java can automatically widen a smaller numeric value into a larger numeric type.

Casting

Explicit narrowing

double
68.1375->cast
(int)->int
68
double total = 68.1375;
int wholeRiyals = (int) total;

Narrowing can lose information, so Java asks you to write the cast.

Casting

Keep decimal division when needed

int students = 10;
int groups = 3;
double average = (double) students / groups;
System.out.println(average);

Cast before division to avoid losing the decimal part.

Section 06

Strings and Output

Text changes how + behaves in an expression.

Textual Operations

+ joins strings

String item = "Notebook";
int quantity = 3;
System.out.println(item + ": " + quantity);
System.out.println("Total items: " + quantity + 2);
System.out.println("Total items: " + (quantity + 2));

Parentheses make text-plus-math output honest.

Formatted Output

printf controls numeric display

double total = 68.1375;
System.out.printf("Total: %.2f%n", total);

%.2f prints two digits after the decimal. %n moves to a new line.

Relational Operations

Comparisons produce booleans

int age = 19;
boolean oldEnough = age >= 18;
boolean exact = age == 19;

We only evaluate these expressions now. We use them for decisions in the next chapter.

Logical Operations

Logical operators combine booleans

boolean hasId = true;
boolean registered = false;
boolean ready = hasId && registered;
boolean needsHelp = !registered;

&& means AND, || means OR, and ! means NOT.

Debug

Common operator mistakes

  • Expecting 5 / 2 to produce 2.5.
  • Writing + = instead of +=.
  • Using = when a boolean comparison needs ==.
  • Reversing operators: =< instead of <=.
  • Forgetting parentheses in string concatenation.
