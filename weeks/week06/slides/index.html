Section 01

Post-test repetition

A do-while loop runs the body first, then checks the condition.

Syntax

do-while

int choice;
do {
    System.out.println("1. Continue");
    System.out.println("0. Exit");
    choice = input.nextInt();
} while (choice != 0);

Full Program

Menu repeats until Exit

import java.util.Scanner;

public class MenuLoop {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int choice;
        do {
            System.out.println("1. Say hello");
            System.out.println("0. Exit");
            System.out.print("Choice: ");
            choice = input.nextInt();
            if (choice == 1) {
                System.out.println("Hello");
            } else if (choice != 0) {
                System.out.println("Invalid choice");
            }
        } while (choice != 0);
        input.close();
    }
}

Section 02

Nested loops

For every one outer-loop iteration, the inner loop can run many times.

Visual Model

Rows and columns

row = 1->col 1,2,3->next row

Full Program

Multiplication grid

public class MultiplicationGrid {
    public static void main(String[] args) {
        for (int row = 1; row <= 5; row++) {
            for (int col = 1; col <= 5; col++) {
                System.out.printf("%4d", row * col);
            }
            System.out.println();
        }
    }
}

Section 03

Jumping statements

break, continue, and return change the normal loop/method flow.

break

Leave the loop

for (int i = 1; i <= 10; i++) {
    if (i == 4) {
        break;
    }
    System.out.println(i);
}

continue

Skip this iteration

for (int i = 1; i <= 10; i++) {
    if (i == 4) {
        continue;
    }
    System.out.println(i);
}

return

Leave the method

public static void main(String[] args) {
    int age = -5;
    if (age < 0) {
        System.out.println("Invalid age");
        return;
    }
    System.out.println("Age accepted");
}

For CS0122, use this as a simple early-exit idea. Detailed methods come later.

Debug

continue in while loops

int i = 0;
while (i < 5) {
    if (i == 2) {
        continue;
    }
    i++;
}

The update is skipped when i == 2. Fix by updating before continue or changing the structure.

Lab

Repeating menu

Use do-while + switch for the menu, nested loops for grids, and break/continue for controlled skipping.

Recap

Three exit ideas

  • break: leave loop or switch.
  • continue: skip to next loop iteration.
  • return: leave current method.
