Section 01

Matrix concept

A matrix stores data in rows and columns. Java represents this as a two-dimensional array.

Visual Model

Rows and columns

col 0col 1col 2
row 0[0][0][0][1][0][2]
row 1[1][0][1][1][1][2]

Syntax

Declare and initialize

int[][] numbers = {
    {1, 4, 2},
    {3, 6, 8}
};

Access

Use row then column

System.out.println(numbers[1][2]); // 8
numbers[0][1] = 9;

Lengths

Rows and columns

int rows = numbers.length;
int columnsInRow0 = numbers[0].length;

Traversal

Nested loops

for (int row = 0; row < numbers.length; row++) {
    for (int col = 0; col < numbers[row].length; col++) {
        System.out.println(numbers[row][col]);
    }
}

Full Program

Matrix processor

import java.util.Scanner;

public class MatrixProcessor {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[][] sales = new int[3][4];
        int total = 0;

        for (int row = 0; row < sales.length; row++) {
            for (int col = 0; col < sales[row].length; col++) {
                System.out.print("Sales row " + row + ", col " + col + ": ");
                sales[row][col] = input.nextInt();
                total += sales[row][col];
            }
        }

        System.out.println("Matrix:");
        for (int row = 0; row < sales.length; row++) {
            int rowTotal = 0;
            for (int col = 0; col < sales[row].length; col++) {
                System.out.printf("%5d", sales[row][col]);
                rowTotal += sales[row][col];
            }
            System.out.println(" | row total = " + rowTotal);
        }

        System.out.println("Overall total: " + total);
        input.close();
    }
}

Row totals

Sum one row at a time

for (int row = 0; row < sales.length; row++) {
    int rowTotal = 0;
    for (int col = 0; col < sales[row].length; col++) {
        rowTotal += sales[row][col];
    }
    System.out.println("Row total: " + rowTotal);
}

Column totals

Rectangular matrix columns

for (int col = 0; col < sales[0].length; col++) {
    int columnTotal = 0;
    for (int row = 0; row < sales.length; row++) {
        columnTotal += sales[row][col];
    }
    System.out.println("Column total: " + columnTotal);
}

Swapped indexes

matrix[col][row] // often wrong when you mean row first
matrix[row][col] // row first, then column

Recap

2D array checklist

  • First index is row.
  • Second index is column.
  • Outer loop often rows.
  • Inner loop often columns.
