    Software Setup

    Students use the same Java tools in lecture, lab, and practice work.

    JDK

    Install a Java Development Kit and verify it with java -version and javac -version.

    Editor

    Visual Studio Code with the Extension Pack for Java.

    Terminal

    Compile with javac FileName.java and run with java FileName.

    Workflow

    Predict output, run the program, explain the result, modify carefully, debug one error at a time.
