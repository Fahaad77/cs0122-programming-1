Practice

Milestones

  1. Week 1: Create, compile, run, and debug a first Java program.
  2. Week 2: Build a console program with variables, data types, constants, and Scanner input.
  3. Week 3: Trace arithmetic expressions, casting, formatting, and textual operations.
  4. Week 4: Complete a menu-driven selection program using validation.
  5. Weeks 5-6: Use while, for, do-while, nested loops, break, continue, and return.
  6. Week 7: Review variables, input, expressions, selection, and loops.
  7. Weeks 8-10: Process one-dimensional arrays and two-dimensional matrices.
  8. Weeks 11-14: Complete integrated project, lab readiness, and cumulative practice work.
